# CSI OAPI Documentation (SAP2000) — Index

Documentation de l'API SAP2000 (CSI OAPI), convertie depuis le fichier CHM d'origine
en fichiers Markdown, regroupés par catégorie fonctionnelle pour faciliter la recherche.

## Contenu

- **Getting_Started.md** — Concepts de base, connexion à SAP2000 depuis une application externe, conventions
- **Example_Code.md** — Exemples complets en VBA, VB, C#, C++, Fortran, MATLAB, Python, IronPython
- **Database_Tables.md** — Fonctions d'accès aux tables de base de données
- **Root_Overview_and_Misc_Functions.md** — Page principale, API distante, fonctions diverses
- **Migration_Notes.md** — Notes de migration entre versions
